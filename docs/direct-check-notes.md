# 표기·인용 대조 및 정리별 검증 명세

본 문서는 원고(`manuscript_en.pdf`, `manuscript_ko.pdf`), 계산 코드(`computation/`, `independent_checks/`), Lean 4 코드(`lean/`) 사이의 표기·가정 대응과 참고문헌 원문 대조 내역을 정리한다.

## 1. 정의·표기 및 경계조건

| 항목 | 정의 및 표기 | 경계조건 |
|---|---|---|
| 그래프 범위 | 유한 단순 무향 그래프 G = (V, E), 위수 n = |V| | 숲(forest)은 비연결 그래프와 고립점을 허용한다. 고립점 제외가 필요한 명제(정리 1.2(ii)–(iii), 보조정리 2.2)는 가정을 명시한다. 모든 꼭짓점이 고립점인 K̄_n (r = n)은 D(K̄_n, x) = x^n으로 단봉이며, 공그래프 규약 D(∅, x) = 1, γ(∅) = Γ(∅) = 0 아래 보조정리 2.3의 식과 일치한다 |
| 닫힌 이웃과 지배집합 | N[v] = {v} ∪ N(v); 모든 u ∈ V에 대해 N[u] ∩ S ≠ ∅일 때 S는 지배집합 | K₁의 유일한 꼭짓점 {v}는 지배집합이며 D(K₁, x) = x, γ(K₁) = Γ(K₁) = 1, h = 0 |
| 계수 d_j(G) | 크기 j인 지배집합들의 모임 D_j(G)의 원소 수 | j < γ(G) 또는 j > n이면 d_j(G) = 0; γ(G) ≤ j ≤ n에서는 항상 d_j(G) > 0 (내부 영점 없음, 보조정리 2.1(i)) |
| 단봉성 (unimodal) | 어떤 지수 m이 존재하여 d_0 ≤ d_1 ≤ ··· ≤ d_m ≥ d_{m+1} ≥ ··· ≥ d_n | 약한 단봉성(weak unimodality). Lean 명제의 `∃ m, (∀ k < m, dR k ≤ dR (k+1)) ∧ (∀ k ≥ m, dR (k+1) ≤ dR k)`와 동일한 조건 |
| 로그오목성 (log-concave) | 1 ≤ j ≤ n − 1에서 d_j² ≥ d_{j-1} d_{j+1} | 음이 아닌 수열에서 로그오목성이 단봉성을 함의하고 다항식 곱에서 보존되려면 내부 영점이 없다는 조건이 필요하다(보조정리 2.1(i), 보조정리 6.2). 계산 코드에서도 `support_failures == 0`을 함께 확인한다 |
| γ(G), Γ(G), α(G) | 최소 지배수 γ(G), 상지배수 Γ(G), 독립수 α(G) | 일반 그래프에서는 α(G) ≤ Γ(G), 이분그래프에서는 Γ(G) = α(G)가 성립한다(식 (4)) |
| 임계 꼭짓점 a(S) | Crit(S) = {v ∈ S : S ∖ {v}가 지배집합이 아님}, a(S) = |Crit(S)| | S가 극소 지배집합일 필요충분조건은 a(S) = |S|. S ⊆ U이면 Crit(U) ⊆ Crit(S)이다(보조정리 2.1(ii)) |
| 평균 c_j, 분산 v_j, 여분 e_j | D_j(G) 위의 균등분포에 대한 a(S)의 평균 c_j, 분산 v_j; e_j = j − c_j | 정의역은 γ ≤ j ≤ n. 식 (5) j − c_j = (n − j + 1) d_{j-1} / d_j에서 j = γ일 때 e_γ = 0이고, γ < j ≤ n에서 j − c_j > 0이다 |
| 나무 개수 표기 | r_n: 위수 n의 루트 나무 수, t_n: 위수 n의 비동형 나무 수 | 2~22정점 9,114,284종(K₁ 포함 9,114,285종), 2~26정점 447,672,595종(K₁ 포함 447,672,596종), 2~27정점 1,198,738,055종(K₁ 포함 1,198,738,056종) |

| Beaton & Schoonhoven (2024), arXiv:2411.02288v1 | 나무 T에서 Lemma 5(하계), Theorem 6(증가 구간), Lemma 15(재구성 논증에 의한 상계), Theorem 16(감소 구간), Corollary 17(Γ(T) − γ(T) < 3일 때 단봉), Theorem 18(avd 경계), Proposition 1(T_k, k ≥ 4, 위수 40 이상 비로그오목) | 보조정리 3.1에서 하계를 숲으로 확장하고, 보조정리 3.2에서 재구성 논증 없이 모든 이분그래프에 성립하는 짧은 상계 증명을 제시함. 비고 6.8에서 k = 3(T₃, 31정점)이 이미 비로그오목임을 명시함 |
| Kadrawi & Levit (2025), *Ars Math. Contemp.* 25(4), #P4.03 | 나무의 독립다항식에서 로그오목성이 깨지는 최소 위수가 26임을 증명 | 1절에서 지배다항식의 최소 위수(27)와 병행 결과로 인용 |
| Omar (2026), arXiv:2601.14494v1 | 지배다항식 단봉성에 관한 충분조건 제시 | 1절 선행연구로 인용 |
| Du, Heilman & Panova (2026), arXiv:2605.02193v1 | PatternBoost로 12정점 그래프 3개 및 32·58정점 비로그오목 나무 제시; 새 뿌리에 T(k,k,k) 사본 m개와 2정점 경로를 붙여 γ+1, γ+3, …, γ+2m−1에서 로그오목성이 깨지는 나무 구성(Theorem 1.2 = 4.10) | 1절에 32·58정점 예시와 다중 지수 구성을 인용하고, 7절에서 명제 7.2의 나무 W가 같은 조각을 다른 구조와 목적으로 결합함을 명시함 |
